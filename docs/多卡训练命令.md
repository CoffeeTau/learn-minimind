先在服务器确认实际分配给你的 GPU 数量：
nvidia-smi -L

python3 -c 'import torch; print("GPU 数量:", torch.cuda.device_count()); [print(i, torch.cuda.get_device_name(i)) for i in range(torch.cuda.device_count())]'
如果能看到 4 张 L40S，从 trainer 目录执行：
cd trainer

CUDA_VISIBLE_DEVICES=0,1,2,3 \
torchrun \
  --standalone \
  --nproc_per_node=4 \
  train_full_sft.py \
  --dtype bfloat16 \
  --batch_size 4 \
  --accumulation_steps 1 \
  --data_path ../dataset/sft_t2t_mini.jsonl \
  --from_weight pretrain
如果有 8 张卡，则改成：
CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 \
torchrun \
  --standalone \
  --nproc_per_node=8 \
  train_full_sft.py \
  --dtype bfloat16 \
  --batch_size 2 \
  --accumulation_steps 1 \
  --data_path ../dataset/sft_t2t_mini.jsonl \
  --from_weight pretrain
这里最容易误解的是 --batch_size：它是每张卡的 batch size，而不是所有卡加起来的 batch size。
\[
\text{有效全局 batch}
=
\text{每卡 batch}
\times
\text{GPU 数}
\times
\text{accumulation steps}
\]例如：
GPU 数	batch_size	accumulation_steps	有效全局 batch
1	16	1	16
4	4	1	16
4	16	1	64
8	2	1	16


因此，如果你想保持原来单卡 batch_size=16 的训练语义：
- 4 卡：每卡 batch_size=4
- 8 卡：每卡 batch_size=2
如果希望增大全局 batch，可以让每卡仍然使用 16，但这时全局 batch 会变大，学习动态也会改变，不能简单认为只是“训练更快”。
